클로드 코드 설정 파일 처리 미흡으로 GitHub에 민감 정보 대량 유출

Ars Technica 2026-11-10 02:24

아르스 테크니카 보도에 따르면 앤스로픽의 클로드 코드가 사용자 승인 설정을 저장하는 방식 때문에 GitHub 공개 저장소에 비밀 정보가 유출되고 있다. 아피이로 연구진은 저장소에 포함된 클로드 코드 설정 파일에서 수천 건의 비밀 정보를 발견했으며, 여기에는 데이터베이스 비밀번호, API 토큰, 루트 로그인 등이 포함됐다. 문제는 사용자가 자동 셸 명령 실행을 ‘예, 다시 묻지 않기’로 승인하면 해당 선택이 로컬 .claude/settings.local.json에 규칙으로 저장되는 과정에서 명령 자체가 그대로 기록되는 점이다. 앤스로픽 문서에는 해당 파일이 개발자 글로벌 .gitignore에 추가된다고 안내돼 있지만, 저장소 수준에는 반영되지 않아 클론이나 폴더가 나중에 저장소가 될 경우 실수로 업로드될 수 있다. 클로드 코드가 설정 파일 변경을 스스로 커밋하는 경우도 있다고 전해진다.
