연결 차량의 데이터 전송 경로와 공유 대상을 추적한 연구 결과

Ars Technica 2026-09-29 23:49

연결 차량의 프라이버시 문제가 다시 확인됐다. 노스이스턴대와 Consumer Reports 연구팀은 19개 브랜드의 21대 차량을 대상으로 실제 주행과 대기 상태에서 네트워크 트래픽을 측정했다. 테스트 결과 광고주와 추적 업체를 비롯해 마이크로소프트와 어도비 같은 빅테크 기업으로 향하는 트래픽 패턴이 관찰됐다. 차량용 동승자 앱을 사용하면 데이터 노출이 더 커지는 것으로 나타났다. 2023년 Mozilla 재단이 자동차 제조사 개인정보 정책을 검토해 최악의 카테고리라고 평가한 바 있다. 이번 연구는 정책 검토가 아닌 실제 차량에서 발생하는 트래픽을 측정했다. 연구진은 11대의 전기차를 Faraday tent에 주차해 셀룰러 신호가 차단될 때 Wi-Fi로 트래픽이 전환되는지를 확인하기도 했다. 수정된 인증서를 이용한 패킷 내용 확인 시도는 모두 실패했지만, DNS 트래픽에서 접촉한 도메인, TLS 핸드셰이크의 Server Name Indication, 전송량과 타이밍, 행동 차이 등 네트워크 흔적으로 유용한 정보를 얻을 수 있었다.
