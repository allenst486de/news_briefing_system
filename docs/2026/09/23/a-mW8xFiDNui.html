오픈AI, GPT-6 계열 소형 모델 솔과 루나 업데이트 발표

TechCrunch 2026-09-23 03:00

오픈AI가 GPT-6 아스트라 이후 라인업을 확장하며 솔과 루나 모델의 업데이트 버전을 선보였다. 회사에 따르면 솔은 코딩 등 복잡한 작업을, 루나는 문서 요약이나 정보 추출 등 명확한 목표의 고빈도 clerical 작업을 겨냥한다. 이번 업데이트는 지능의 효율성과 접근성을 높이는 데 초점을 뒀다고 설명됐다. API 접근 비용은 5.6 세대 솔과 루나 대비 절반 수준으로 인하됐으며, 회사는 캐싱과 추론 개선 덕분이라고 밝혔다. 또한 최신 모델이 사실적으로 정확한 답변을 생성하는 능력이 개선되고 오류율이 낮아졌다고 주장했다. 구체적인 수치나 벤치마크 결과는 원문에 포함되지 않았다.
